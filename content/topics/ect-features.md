The Euler Characteristic Transform (ECT) is an injective shape descriptor. We have recently shown a continuous encoding for the ECT [1]. Since this encoding is vertex-based, it is easy to include additional vertex features. In this project, you will implement this for lidar data with color channels. As a baseline model, you will use PointNet++.
