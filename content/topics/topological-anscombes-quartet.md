This topic is based on the classical Anscombe's quartet and families of point sets with identical 1D persistence [1]. The goal is to generate more interesting datasets using the simulated annealing methods presented in [2]. This project is mostly computational.

## References

[1] Families of point sets with identical 1D persistence. [arXiv:2202.00577](https://arxiv.org/abs/2202.00577)

[2] Same Stats, Different Graphs: Generating Datasets with Varied Appearance and Identical Statistics through Simulated Annealing. [CHI 2017](http://library.usc.edu.ph/ACM/CHI%202017/1proc/p1290.pdf)
